技能系统（4 类型）
主动 / 被动 / 辅助 / 封印
5 门派 × 9 技能 = 45 技能，按解锁等级消耗银两学习
装备系统（6 品质 × 6 部位）
品质：白 → 蓝 → 紫 → 金 → 神 → 圣（属性 1.0x → 6.5x）
部位：武器 / 头盔 / 盔甲 / 靴子 / 戒指 / 手镯
龙宫专属武器：黄袍武器 → 龙鳞叉 → 龙鳞破天叉 → 青龙叉 → 青龙在天叉 → 天龙叉 → 龙王叉 → 诛仙叉
副本系统
15-90+ 级副本，含普通/困难双难度
普通掉落白/蓝/紫装，困难掉落金/神装
副本按区域分布：长安 / 宝象国 / 乌鸡国 / 傲来国 / 天宫 / 地府
宠物系统
最多携带 8 只，同时只能出战 1 只
出战宠物获得人物 20% 经验
宠物等级不能超过人物等级
世界地图（9 区域）
新手村 → 长安城 → 开封府 / 宝象国 / 乌鸡国 / 傲来国 / 天宫 / 地府 / 蓬莱仙岛 → 西天灵山
货币系统
银两：基础货币（日常交易/升级装备）

修炼挂机
封顶 4 小时
每小时 500 经验 / 200 银两
到时间领取收益自动升级

拜师成功直接奖励 1000 万经验
徒弟升级出师，师傅获得大量声望/经验/道具
