核心循环
拿食材 → 做菜 → 上桌营业 → 顾客消费 → 金币/经验/熟练度 → 升菜等/升星级 → 去好友家补缺口 → 回店经营
双主轴
餐厅星级（规模）：决定桌位/厨柜/服务员位/顾客流量
菜谱等级（内容）：决定售价/收益/满意度/收集进度
星级 0-5（Lv1→Lv70）· 菜谱 1-6级 × 3品质（普通/极品/金牌）
基础数值
开局金币 10000 · 顾客周期 180秒
1名服务员服务 3桌 · 油壶初始 3000（可扩至8000）
经验公式：need(L→L+1)=120+80×L
菜谱系统
6级菜：1级(Lv1,18金,30s) → 6级(Lv65,320金,180s)
品质系数：普通1.0 / 极品1.25 / 金牌1.55
品质只升售价，不升经验（保留旧逻辑）
升级需：熟练度 + 金币 + 菜谱碎片（升金牌还需特殊调料）
顾客系统
1星起出现挑剔客10%，每升1星+10%（5星上限40%）
2星起出现稀有客，5星达12%
挑剔客金币×1.25 · 稀有客金币×1.60
缺油/缺菜/等待过久 → 满意度下降 → 收益下降
油量系统
做菜耗油 + 每桌每周期待机耗油2
油量0 → 停业 · 油量低 → 效率下降
油壶扩容（8 档）：
3000默认 → 4000初级金币 → 5000中级积分 → 5500高级(上)
→ 6000高级(下) → 7000黄金(上) → 8000黄金(下) → 9000白金(上)
spec 原档：5500/6000/7000/8000 元宝，9000 活动；本平台只有金币，统一折算
怀旧优化：离线只影响效率，不崩盘
翻橱柜（怀旧核心）
日限 15次 · 同好友日限 3次 · 冷却 10分钟
收益衰减：第1次100% → 第2次70% → 第3次40% → 第4次0%
大堆叠额外掉落 · 食材可上锁防翻 · 被翻者得补偿
蟑螂恶作剧
日限 2次 · 封1桌 · 15分钟自动消失 · 单餐厅上限3只
怀旧优化：轻恶作剧，非高压惩罚
服务员
雇好友12小时/500金 · 加成：金币+3%/满意度+2%/速度-5%
含系统默认1名，星级决定总服务员位
设施（24小时）
奖杯(经验+1) / 海报(金币+1) / 保鲜柜(防翻-50%)
省油灶(耗油-10%) / 卫生香氛(蟑螂-50%)
