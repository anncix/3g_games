风云三国 › 规则
核心定位
以三职业三阵营为基础的怀旧三国 MMORPG。
主循环：演武/副本 → 获得经验银两 → 升级换装学技能 → 挑战更高副本 → 继续养成争霸
职业系统（3 职业）
战士：高血量高防御，近战坦克
刺客：高暴击高闪避，敏捷输出
术士：高攻击高内力，远程法师
阵营系统（3 阵营）
魏 / 蜀 / 吴 三国势力
跨阵营 PK 可获得荣誉值
等级与经验
等级上限 60
升级所需经验：need(L) = 100 + 80×L
每升一级按职业自动增加属性
技能系统（4 类型）
主动 / 被动 / 辅助 / 状态
3 职业 × 10 技能，按解锁等级消耗银两+经验学习
装备系统（5 品质 × 7 部位）
品质：普通 / 精良 / 卓越 / 史诗 / 神器
部位：头 / 手 / 衣 / 腿 / 鞋 / 裤子 / 饰品
神器价 = 2×史诗价 = 4×卓越价（同等级）
副本系统
按阵营 × 等级段划分（16-60 级）
56-60 级终极副本三阵营通用
胜利获得经验+银两
军团系统（5 级）
创建需等级≥15 + 500000 银两
1-5 级，最大 100 人
成员可捐献贡献值
称号系统
前缀 + 后缀可组合，配对激发隐藏属性
如 霸+王=霸王，神+仙=神仙，天+帝=天子
成就系统
3 难度（简单/中等/困难）× 9 类型
成长 / 任务 / 杀怪 / PK / 山庄 / 社交 / 副将 / 道具 / 装备
达成获得属性加成
演武系统
演武封顶 6 小时
每小时 300 经验 / 150 银两
周一经验 10 倍加成
荣誉系统
击杀不同阵营玩家获荣誉：
战胜高等级 +15 · 低10级内 +10 · 低10-20级 +5 · 低20级以上 +0
