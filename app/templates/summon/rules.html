核心循环
进地图 → 刷关卡(遭遇战) → 抓捕幻兽 → 组队 → 升级 → 解锁高段位 → 收集图鉴
双轴成长
召唤师等级（1-80）：决定段位解锁/出战位/魔魂槽
幻兽图鉴（120只）：6族×8段位×4稀有度，每只独立个体属性
基础数值
经验公式：need(L)=120+80×L（方案A）
活力上限 120 · 每5分钟+1 · 普通关2/精英关4
出战位 3（Lv60解锁第4位）
种族克制（环形）
水>龙>羽>虫>兽>亡灵>水
克制方伤害 +12% · 被克方 -10%
稀有度
普通(N) / 稀有(R) / 史诗(E) / 传说(L)
成长系数 N1.0 / R1.08 / E1.16 / L1.25
成长星 1-5（倍率1.0-1.25）
抓捕系统
球倍率：普通×1.0 / 强力×1.5 / 超级×2.2
基础率：N0.35 / R0.22 / E0.12 / L0.06
成功率 = 基础率×球倍率 + 级差加成 + 保底加成
级差：玩家高于宠物 +0.01~+0.10，低于 -0.02~-0.20
保底：连续失败 N8/R10/E12/L15 次触发 +0.08~0.10
日限 60次
战斗公式
物伤=(物攻×技能系数-物防)×种族系数
法伤=(魔攻×技能系数-魔防)×种族系数
暴击率5% · 暴击×1.5 · 按速度降序行动
技能系统
60基础技能 × 3阶 = 180技能
阶倍率：1阶1.0 / 2阶1.35 / 3阶1.75
5系：PHY物攻/TANK坦克/MAG法攻/CTRL控制/CURSE诅咒
段位地图（T1-T8）
每10级一段，每段15关，每5关精英
通关一段自动进入下一段位
等级解锁
Lv1：地图/抓捕 · Lv10：擂台/战骨
Lv20：T2 · Lv30：魔魂(3槽) · Lv35：战灵/战灵塔
Lv40：战场/师徒/T4 · Lv60：第4出战位
