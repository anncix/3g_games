花园 › 规则
玩法主循环
播种 → 等待成长 → 阶段操作(浇水/除草/除虫) → 收花 → 入库/卖出/合成 → 点亮花谱 → 展示/互动 → 回到播种
等级与经验
经验来自劳动：播种+2 / 浇水除草除虫+3 / 收获+5 / 点亮花谱+15 / 帮好友+2
每级所需经验 = 等级 × 80
等级影响：可种花种 / 花盆数量 / 商店可购买项
三概念分离
花种(Seed)：播种用，决定成长时间/产量/可产出花朵
花朵(Bloom)：收获得到，有颜色/稀有度/售价
花谱项(AlbumEntry)：图鉴条目，按系列分组，点亮有奖励
同一花种可随机产出多种颜色花朵
阶段状态机
空地 → 已播种 → 发芽期 → 花苗期 → 花蕾期 → 成熟 → 收获 → 空地
发芽/花苗/花蕾期各需一次操作：浇水/除草/除虫
完成2+护理 → 产量+1；不操作不毁花，仅影响收益
好友互动
偷花：成熟花可偷1朵，每盆限偷1次，被偷有消息提醒
帮忙：帮好友浇水/除草/除虫，+2经验+5金币
送花：送好友花朵，强社交
上锁：花盆可上锁防偷
稀有花获取
1. 随机掉落：种植有概率出稀有色
2. 合成路线：用基础花/材料换稀有花种（合成工坊）
3. 活动兑换：材料换传说花种（兑换中心）
最稀有花不直接卖商城
事件上报
模块只上报事件，平台统一处理：
花谱点亮→图标/成就/排行；被偷→消息提醒；收获→成就进度
