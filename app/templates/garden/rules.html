花园 › 规则
玩法主循环
播种 → 等待成长 → 阶段操作(浇水/除草/除虫) → 收花 → 合成/兑换 → 点亮花谱 → 展示/互动 → 回到播种
等级与经验（方案A）
升级所需经验：need(L→L+1) = 120 + 80×L
经验来自劳动：播种+2 / 浇水除草除虫+3 / 收获(3+物品等级×2) / 点亮花谱(15+物品等级×5) / 帮忙+2 / 合成(5+目标等级×3)
等级影响：可种花种 / 花盆数量 / 物品等级上限
魔法师称号体系（16段位）
每5级一段：见习/学徒/初阶/中阶/高阶/精英/大魔法师/魔导师/大魔导师/贤者/奥术贤者/秘法宗师/元素宗师/大元素使/星辉大法师/传奇魔法王座
段位起始等级(1/6/11/16/...)为强解锁点：新花盆/新花种
物品等级 × 稀有度 双轴
物品等级 Lv1-8（强度轴）
稀有度：普通/稀有/史诗/传说（获取难度轴）
玩家等级段→物品上限：1-10→≤2, 11-20→≤3, 21-30→≤4, 31-40→≤5, 41-50→≤6, 51-65→≤7, 66-80→≤8
三概念分离
花种(Seed)：播种用，决定成长时间/产量/可产出花朵
花朵(Bloom)：收获得到，有颜色/稀有度/物品等级/售价
花谱项(AlbumEntry)：图鉴条目，按系列分组，点亮有奖励
阶段状态机
空地 → 已播种 → 发芽期 → 花苗期 → 花蕾期 → 成熟 → 收获 → 空地
完成2+护理 → 产量+1；不操作不毁花，仅影响收益
合成工坊（怀旧但可控）
成功率随目标等级下降；失败累计保底值满必成（防挫败）
高阶合成(≥Lv6)强制操作锁校验（风控）
好友互动（日限+衰减）
偷花：每日10次，前3次满额，4-6次半额，7-10次仅花无奖励
帮忙：每日10次，+2经验+5金币
送花：送好友花朵
上锁：花盆可上锁防偷
风控与客服
高价值操作强制校验；行为限速；操作留痕可追溯（用户+时间+资源变化）
订单交易系统（v0.1.3 新增 · spec 经济主引擎）
定位：产出 → 订单交付 → 金币/经验回收（闭环收获消费路径）
订单类型：普通单(margin 1.15) / 加价单(1.45) / 限时单(1.75，8小时)
需求生成：从已点亮花谱的花朵中抽取 1-3 种，每种 1-3 个
奖励公式（spec）：
V_req = Σ(qty × value_coin × Q_value_mul)
R_coin = floor(V_req × margin × urgency × difficulty)
R_exp = floor(R_coin^0.6 × exp_scale(L))
刷新：每日 2 次免费，之后 cost = 50 × 1.5^n（防刷递增）
同时进行：上限 6 单
统一加成公式（v0.1.3 · spec 必须写死）
final = base × (1 + Σadd) × Π(1 + mul_i)
关键项有 cap 上限（例：成长减免最多 80%）
长期加成边际递减（环境值等）
品质系统（v0.1.3 新增 · spec 核心长期追求）
5 档：N普通 / G优良 / R稀有 / E史诗 / L传说
权重抽取：W_q = W_base × (1 + buff) × env_quality_mul（避免概率叠爆）
env 边际递减：env_quality_mul = 1 + 0.3×(1 - exp(-env_score/50))
品质对订单价值倍率：N1.0 / G1.1 / R1.25 / E1.45 / L1.7
物品价值体系（v0.1.3 · spec 定价底座）
四段式：时间价值 + 稀有溢价 + 加工溢价 + 活动溢价
V_crop_base = T_grow_hours × V_time_unit(L) / plot_efficiency
V_time_unit(L) = 8 + 0.5×L
稀有度倍率：普通1.0 / 稀有1.8 / 史诗2.6 / 传说4.0
value_coin 用于订单/配方定价，不等于玩家可见卖价
大全级资料库（v0.1.4 新增 · spec 物品体系/订单系统分册）
资料库规模：作物 520 / 材料 1024 / 配方 1536 / 订单模板 3072
8 tier 分层：T1-2 普通 / T3-4 稀有 / T5-6 史诗 / T7-8 传说
解锁等级：1/6/11/16/21/31/46/66（对齐段位起始等级）
订单池：按 spec pool(L) 分层，level_min = tier 解锁等级
闭环：订单需求 70% 取花朵(收获产出) / 30% 取材料(工坊产出) → plant→harvest→deliver
幂等：生成器 need = TARGET - current 填至目标，重跑 0 新增
