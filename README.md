# QQ家园怀旧平台 - QQ Games

一个复刻经典WAP手机QQ家园的怀旧游戏平台，包含多款当年的经典文字游戏。

> **当前版本：v0.3.2** — 全量数据迁移 + 双新模块 + 全模块运行修复

## 版本更新记录

### v0.3.2（全量重构版）
- 以 qqgames 为主体重构全部数据，迁移并合并 3g_games 既有 8 个游戏模块
- 新增多币种钱包系统（G币/金币/元宝/银两），统一货币流水与公共背包/商城
- 新增 **风云三国** 模块（13城市/30技能/105装备/13副本/15称号/21成就/189物品）
- 新增 **新西游记** 模块（10场景/45技能/108装备/22副本/13宠物/14药品/19材料/12坐标）
- 全部 8 个游戏模块首页模拟运行验证通过（HTTP 200）
- 修复各模块模板与重构后模型字段不一致、种子数据幂等性问题

## 技术栈

- **后端**: FastAPI + SQLAlchemy + SQLite
- **前端**: Jinja2 模板 + WAP风格CSS
- **认证**: JWT + bcrypt
- **部署**: Uvicorn

## 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行服务器
```bash
python main.py
```

访问 http://localhost:8000

### 默认账号
- 管理员: `admin` / `admin123`
